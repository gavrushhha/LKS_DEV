# Frontend (следующий этап)

Интерфейсы ЛКС на React или Vue. На этапе 1 не разрабатывается: контракты API
фиксируются в `../backend/openapi/openapi.yaml`.

Планируемая структура:

```
src/
  app/          # маршрутизация, провайдеры
  pages/        # расписание, журнал, ведомости, справочники
  entities/     # модели и API-клиенты
  features/     # фильтры, выставление оценок, закрытие ведомостей
  shared/       # ui-кит, утилиты, http-клиент
```
