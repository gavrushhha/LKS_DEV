# Документы проекта

* `ТЗ_этап1_расписание_журнал.docx` — техническое задание этапа 1
* `ЛКС_этап1_расписание_журнал.openapi.yaml` — контракт API
* `backlog/ЛКС_этап1_бэклог.xlsx` — задачи и подзадачи с оценками
* `adr/` — архитектурные решения
* `coding_standards.md` — стандарты оформления кода и Git-процесса (backend, frontend)

## Как обновлять

ТЗ и бэклог ведутся как артефакты: при изменении модели данных или контракта
обновляется сначала OpenAPI-спека, затем ТЗ, затем задачи в Трекере.
