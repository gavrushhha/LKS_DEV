# НСИ и локальная БД расписания

По предоставленным требованиям НСИ отправляет REST JSON в ЛКС на `POST /nsirest/` с Basic Auth. Это входящий адрес нашего адаптера, не адрес для исходящих запросов ЛКС в НСИ. Реквизиты должны храниться в настройках окружения, а не в исходном коде или журнале. HTTP с Basic Auth не шифрует пароль; защиту канала нужно согласовать с администраторами.

В репозитории приёмник `/nsirest/` и обработка сообщений не реализованы. Ограниченная загрузка из БД Тандема не является приёмом push-событий. Успешный `callCC: 0` должен означать выполненную операцию, а не только доступность приложения.

## Требования к адаптеру

- `retrieve`: получение данных по запросу НСИ; правила фильтров и начальной загрузки требуют уточнения.
- `insert`, `update`, `delete`: обработка уведомлений и изменение локальных данных ЛКС. Повторная доставка не должна создавать дубликаты, а частичное обновление не должно затирать отсутствующие поля.
- `commit`: подтверждение пакета; семантику и связь с сохранением требуется сверить с регламентом и реальными сообщениями.
- Сообщение содержит `routingHeader` и `datagram.x-datagram`; ответ — `callCC`, `callRC`, обратные идентификаторы маршрутизации и датаграмму. Точные схемы сущностей и ошибки требуют проверки.
- Нужны атомарность, идемпотентность и сохранение результата обработки, чтобы повторные сообщения не терялись и не подтверждались преждевременно. Не логировать учётные данные или лишние персональные данные.

## Расписание и справочники

Среди предоставленных типов есть `TimeTableEventRealType`, `TimeTableVersionType`, `AcademicGroupType`, `PlaceType`, `TtEvent2PpsType`, `TtEventReal2EduGroupType`, `ScheduleEventPlaceType` и `RegistryDisciplineType`. Их фактические поля, ссылки и соответствие SQL-таблицам необходимо проверить по схемам и примерам. Статус «чтение и изменение» не разрешает прямую запись в БД Тандема. Для `TtEventReal2EduGroupType` указан доступ только на чтение.

Нужно определить начальное заполнение, состав push-событий и обработку опоздавших сообщений; сопоставить UUID НСИ и bigint SQL-источника. Прямая запись SQL в Тандем запрещена.

Для одной группы за 06–19.12.2026 проверено 46 занятий: все с номером пары, максимальная длина `place_p` — 12; `activity_p`, `pps_p`, `students_p` во всей выборке `NULL`. Это не доказывает отсутствие дисциплин, преподавателей или групп в источнике. Нужно проверить связанные таблицы и сообщения НСИ.

Далее: сверить регламент и JSON-схемы, спроектировать хранение пакетов и справочников, реализовать защищённый приём, затем проверить локально и согласованно на DEV. Файл `dev-proxy` менять запрещено.
