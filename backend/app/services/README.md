# Сервис снимка расписания

`sync_schedule_snapshot(reader, session, kind, source_id, date_from, date_to)` читает расписание по одному фильтру и периоду, сохраняет новый снимок в БД ЛКС и переключает указатель в одной транзакции. Возвращает UUID снимка строкой. Сессия должна быть свободна от незавершённой транзакции. Ошибка отменяет запись; предыдущий снимок остаётся активным.

В снимке также сохраняются ID преподавателей и аудиторий из подтверждённых связей Тандема. Связи и занятия записываются в одной транзакции; наличие записи в локальном справочнике не требуется. Запрос ещё нужно проверить на PostgreSQL и оценить его план на Тандеме.

При 200 строках или более возникает `IncompleteSnapshotError`: страницы пока не реализованы, поэтому полнота неизвестна. Пустой успешный ответ сохраняется как пустой снимок. Область — точная комбинация фильтра, ID и обеих дат; пересекающиеся периоды не объединяются. Повтор при конфликте одновременной первой загрузки не реализован. Сервис не подключён к API или планировщику и не проверен на PostgreSQL.

Повторяющиеся ID занятий или занятия за пределами периода отклоняются до сохранения. Пустые текстовые поля источника сохраняются как `None`.

`read_schedule_snapshot(session, kind, source_id, date_from, date_to)` читает активный готовый снимок для точного сочетания фильтра и периода. Возвращает `SnapshotResult` с идентификатором, временем завершения и занятиями; `None` означает отсутствие готового снимка, а пустой список занятий — успешно сохранённый пустой снимок. Это внутренний интерфейс, пока без подключения к API.

`read_snapshot_links(session, snapshot_id)` возвращает связанные с занятиями снимка ID преподавателей, помещений, учебных групп и дисциплин, а также имена из локальных справочников при наличии. Соответствие учебных групп академическим функция не определяет. Цепочка дисциплин проверена на одной группе и требует проверки на других данных.

Адаптер `app.integrations.nsi`: `verify_nsi_auth()` проверяет настройки и Basic Auth, `receive_nsi_message()` возвращает ошибку `callCC: 2` для ещё не реализованных операций. Параметры: `NSI_BASIC_USERNAME`, `NSI_BASIC_PASSWORD`, `NSI_DESTINATION_ID`; без учётных данных приёмник недоступен. Адаптер не сохраняет сообщения и не готов для подключения НСИ.

`save_schedule_dictionary_item(session, item)` сохраняет группу, аудиторию или преподавателя в текущей транзакции. `save_schedule_discipline(session, item)` сохраняет дисциплину: ей необходимо передавать только результат методов чтения дисциплин, не произвольную запись реестра. Вызывающий код завершает транзакцию; автоматическая загрузка и обработка НСИ пока не подключены.

`sync_dictionary_page(reader, session, kind, after_id=None, limit=100)` читает и сохраняет одну страницу выбранного справочника в одной транзакции. Возвращает количество записей и курсор продолжения (или `None` в конце). Пустая страница не удаляет данные. Фоновый запуск и обработка удалений не реализованы.

`read_dictionary_page(session, kind, after_id=None, limit=100)` читает страницу локального справочника, возвращая записи и курсор следующей страницы либо `None`. ID сортируются как строки в БД ЛКС; этот курсор не совместим с числовым курсором чтения Тандема. Пока функция не подключена к HTTP API.

`read_dictionary_item(session, kind, source_id)` находит одну запись локального справочника или возвращает `None`.

`sync_dictionary_batch(reader, session, kind, after_id=None, page_size=100, max_pages=5)` сохраняет до 10 страниц; возвращает количество страниц и записей, курсор и признак завершения. Каждая страница фиксируется отдельно. При ошибке `DictionarySyncError.progress` содержит курсор последней сохранённой страницы. Это не атомарный снимок всего справочника; удалённые записи не обрабатываются.
