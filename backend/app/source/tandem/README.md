# Чтение данных Тандема

Слой `source/tandem` готовится для чтения из БД Тандема. Прямую запись в источник и локальное дублирование он не выполняет. Функции пока не подключены к действующим эндпоинтам; SQL и интерфейсы требуют проверки и согласования.

## Подключение

* `TandemClient.connect()` — создаёт пул подключений только для чтения при первом вызове.
* `TandemClient.fetch(query, *args)` — выполняет запрос с параметрами в read-only транзакции и возвращает строки.
* `TandemClient.close()` — закрывает пул.
* `get_tandem_client(request)` из `app.core.deps` — получает общий клиент приложения и подключает его при обращении.

## Справочники

Методы `TandemDictionaryReader` принимают числовые ID Тандема и возвращают модели с ID в виде строки. Методы с суффиксом `_page` принимают `after_id` и `limit` и возвращают страницу из не более 200 записей. Если объект по ID не найден, возвращается `None`.

* `group_by_id(group_id)` — академическая группа по ID.
* `groups_page(after_id=None, limit=100)` — страница академических групп.
* `room_by_id(room_id)` — аудитория по ID.
* `rooms_page(after_id=None, limit=100)` — страница аудиторий.
* `teacher_by_id(teacher_id)` — преподаватель по ID роли.
* `teachers_page(after_id=None, limit=100)` — страница преподавателей.
* `teachers_by_name(first_name, last_name, after_id=None, limit=100)` — преподаватели по полному имени и фамилии без учёта регистра.
* `registry_elements_page(after_id=None, limit=100)` — страница записей реестра.
* `disciplines_page(after_id=None, limit=100)` — страница записей, связанных с таблицей дисциплин.
* `disciplines_by_title(query, after_id=None, limit=100)` — поиск дисциплин по подстроке названия без учёта регистра.

Результаты справочников могут включать архивные или выбывшие записи и пустые поля. Результаты поиска и SQL ещё нужно сверить с реальной БД. Поле кода дисциплины и UUID для API не согласованы.

## Расписание

* `TandemScheduleReader.fetch(kind, source_id, date_from, date_to, limit=50)` — исходные строки расписания по группе, преподавателю, аудитории или студенту за период.
* `TandemScheduleReader.fetch_core(...)` — те же строки с преобразованием подтверждённых основных полей.
* `minutes_to_time(value)` — перевод минут от полуночи в строку `HH:MM`; `None` остаётся `None`.
* `map_schedule_core(row, fetched_at)` — преобразование основных полей строки в `ScheduleCore`; время чтения должно содержать часовой пояс.
* `unresolved_schedule_fields()` — список полей расписания, для которых ещё не указан источник в БД.

`ScheduleCore` не является полным ответом API. Обработка пустых границ версии, отмен, чётности и истории состава групп требует подтверждения.

Подробнее о параметрах, моделях и ограничениях — `docs/tandem_read_interface.md` в корне репозитория.
